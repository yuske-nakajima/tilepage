## resize 戦略の実装

`src/flow/reflow.ts` が ResizeObserver による stream 再分配を担う。状態遷移は `idle → pending (1 raf debounce) → reflowing → draining (蓄積された notify を 1 回吸収) → idle`。`isReflowing` フラグで reflow 中の自己発火を吸収し無限ループを防ぐ。

| 状態 | 意味 | 次の遷移 |
|------|------|----------|
| `idle` | アイドル | ResizeObserver 発火で `pending` へ |
| `pending` | 1 animation frame 後の reflow を予約済み | frame 経過で `reflowing` へ |
| `reflowing` | `distribute(book)` 実行中。`isReflowing=true` で通知吸収 | 完了後 `draining` または `idle` へ |
| `draining` | reflow 中に積まれた通知を 1 回まとめて処理する | 完了後 `idle` へ |

## obstacle 反映の論理プロパティ化

`reflowObstacles` で float の `inlineSize` / `blockSize` / `shapeOutside` polygon 座標は column box に対する % で表現する。物理 px を CSS に渡さない (評価軸 #4)。

# バージョニングルール

tilepage は [Semantic Versioning](https://semver.org/spec/v2.0.0.html) に準拠する。

## バージョン判断基準

| 変更内容 | バージョン |
|---|---|
| 破壊的変更（API 削除・変更） | メジャー（0.x の間はマイナー） |
| 機能追加（後方互換） | マイナー（0.x の間はパッチ） |
| バグ修正 | パッチ |
| 依存パッケージのアップデート（runtime deps） | パッチ |
| devDependencies のみのアップデート | バージョン変更なし |
| ドキュメント・CI のみの変更 | バージョン変更なし |

## 0.x 期間の特別ルール

- 1.0.0 未満は安定版ではないため、破壊的変更をマイナーで扱う
- 1.0.0 リリース後は通常の Semantic Versioning に移行する
